# Local Demands Front
pagina simples contendo uma tabela onde apresenta as demandas registradas, juntamente com um formulario que permite adicionar novas.

## Registro de uma nova demanda

O processo de registrar uma nova demanda executa três etapas, na seguinte ordem:

1. Registro dos endereços, caso ainda não existam.
2. Registro do morador, caso ainda não exista.
3. Registro da demanda.
